# Placement Readiness Tracker

## Purpose
This Python project records students' practice-test
scores and calculates their performance.

## Features
- Stores student information.
- Accepts new student records.
- Validates scores between 0 and 100.
- Calculates student averages.
- Assigns grades.
- Identifies the top scorer.
- Identifies students needing extra practice.
- Solves the runner-up score problem.

## Requirements
- Python 3

## How to Run

Run the main program:

python main.py

Run the runner-up problem:

python runner_up.py
